# CO₂ 추진 보조 배관 로봇 Gazebo 시험 및 기록 검증

- 시험 진행: 2026-10-29 대화 및 저장 기록 기준
- 보고서 작성·기록 재검증: 2026-11-09
- 대상: 중앙 관절 없는 6바퀴 차체의 수평 → 수직 → 수평 배관 이동
- 검증 범위: 저장된 SDF·제어 코드·궤적 CSV·결과 JSON의 일치 여부. 이번 문서 작성 중 새로운 물리 시뮬레이션이나 실물 시험은 수행하지 않았다.

## 1. 결론

**현재 가정 모델에서 3 N 연속 추진과 바퀴 구동을 함께 사용하면 총 질량 400 g까지 목표 지점에 도달했으며, 20 g 간격으로 검사한 최초 미도달 조건은 420 g이다.** 420 g은 60초의 시뮬레이션 시간을 주어도 위쪽 수평관에 도달하지 못했다. 400 g과 420 g의 경계 재실행에서도 같은 분류가 나왔다.

이는 실제 CO₂ 카트리지의 적재 한계를 입증한 결과가 아니다. 일정한 추진력, 임의의 마찰·스프링 값, 속도별 특성을 생략한 모터 모델에 대한 결과이다. 검사하지 않은 400~420 g 사이 질량의 한계는 미확정이며, 질량에 따른 성능의 단조성도 일반적으로 보증하지 않는다.

## 2. 설계와 시험의 변화

1. 초기에는 수직 진입 후 3 N을 2초간 가했다. 곡관 진입 전으로 분사 시작을 옮기고, 앞쪽 기준 위치를 55 cm에서 40 cm로 변경했다.
2. 사용자가 상승 중 연속 분사를 요청하여 **2초 제한을 해제**했다. 현재 SDF에 남아 있는 `duration=2.0`은 `continuous=true`일 때 종료 조건으로 사용되지 않는다.
3. 수평 → 수직 경로에서 관절형/일체형과 3 N/6 N을 비교했다.
4. 일체형 + 3 N 조건에 두 번째 곡관과 위쪽 수평관을 추가했다.
5. 이 최종 경로에서 300 g부터 20 g씩 총 질량을 증가시켰다.

초기의 2초 분사 실패와 현재 연속 분사 결과는 조건이 다르므로 직접 같은 성능으로 비교하면 안 된다.

관절형 비교 모델은 55 × 25 × 25 mm 몸체 두 개(각 105 g)를 수동 피치 관절로 연결했다. 관절 범위는 ±1.2 rad(약 ±68.8°), 감쇠는 0.004 N·m·s/rad이다. 일체형은 사이 공간을 채운 단일 상자여서 중앙 관절뿐 아니라 접촉 형상과 관성도 달라진다. 따라서 비교 결과를 관절 유무 하나의 효과로만 단정하지 않는다.

### 추진력과 마찰

| 항목 | 설정 및 의미 |
| --- | --- |
| 분사 시작 | 앞바퀴 단면 중심의 세계 x좌표가 0.40 m 이상일 때. 첫 곡관보다 200 mm 전 |
| 추진력 | 최종 경로·질량 시험은 **3 N 연속**, 강화 비교는 6 N |
| 힘 방향 | 몸체의 전방 +X축을 세계 방향으로 변환. 몸체가 꺾이면 힘 방향도 바뀜 |
| 작용 위치 | 몸체에 순수 힘 적용, 노즐 오프셋에 의한 추가 토크 없음 |
| 분사 검출 | 시뮬레이터 위치를 직접 사용하는 이상적 검출. 실제 센서 모델 아님 |
| 배관 마찰 입력 | `mu=mu2=0.6` |
| 바퀴 마찰 입력 | `mu=mu2=0.8` |
| 몸체 마찰 | 명시 계수 없음, 엔진 기본 처리에 의존 |

0.6과 0.8은 표면별 입력값이며 실제 접촉 마찰계수 측정 결과가 아니다. 최종 조합은 엔진의 접촉 처리에 의존하므로 임의로 두 값을 곱하거나 작은 값만 실제 계수라고 단정하지 않는다. 바퀴 접촉·미끄러짐은 계산하지만, 실제 타이어 변형·구름저항·젖은 표면·오염을 보정한 모델은 아니다.

300 g의 무게는 약 2.943 N이므로 수직 자세에서 3 N은 무게와 비슷하다. 바퀴 토크/반지름의 이상적 구동력 합계는 6 × 0.004 / 0.015 ≈ 1.60 N이나, 실제 전달력은 접촉과 마찰에 제한된다. **본 시험은 가스만으로 상승하는 시험이 아니라 바퀴 모터와 가상 가스 추진을 함께 쓰는 시험**이다. 420 g의 무게는 약 4.120 N이지만, 이 수치만으로 실패 원인이나 경계를 정확하게 설명할 수는 없다.

## 4. 성공 판정과 시험 시간

시간은 실제 대기 시간이 아닌 시뮬레이션 출발 시각 기준이다. 약 0.05초 간격으로 기록하므로 표의 시간은 최초 기록 샘플의 시각이며 정밀 센서 계측치가 아니다.

| 판정 | 조건: 앞바퀴 단면 중심 기준 |
| --- | --- |
| 수직 진입 | \|x−0.75\| < 0.04 m, \|y\| < 0.04 m, 0.50 ≤ z ≤ 1.05 m, 전방 단위벡터 z성분 > 0.7 |
| 위 수평관 진입 | 1.00 ≤ x ≤ 1.50 m, \|y\| < 0.04 m, \|z−1.20\| < 0.04 m, \|전방 단위벡터 z성분\| < 0.3 |
| 최종 목표 | 위 수평관 조건을 만족하면서 x ≥ 1.40 m. **출구 10 cm 전** |

판정은 앞 단면 기준이며, 모든 바퀴의 연속 접촉이나 차체 전체 탈출·정지를 보증하는 기준은 아니다. 관 끝을 지난 뒤에도 추진력이 유지되므로 이후 최고 높이·최종 좌표는 배관 주행 성능에서 제외한다.

질량별 기본 제한은 30초이다. 목표에 도달하면 일찍 종료한다. 최초 미도달 질량은 60초로 연장하고, 직전 성공 질량과 실패 질량을 seed 43으로 재실행했다(기본 seed 42). 이는 제한적인 수치 재현성 확인이며 물리적 조건의 변동이나 통계적 성공률을 검증한 것은 아니다.

## 5. 차체 형태와 추진력 비교: 수평 → 수직

이 비교는 두 번째 곡관을 추가하기 전의 경로이며 질량 증가 시험과 별개의 시험이다. 총 질량 300 g, 40 cm에서 연속 분사, 각 조건 시뮬레이션 12초·seed 42·1회이다.

| 관절형 / 3 N | 곡관에서 정체, 수직 진입 미확인 | 미도달 |
| 일체형 / 3 N | 수직 구간 상단 기준 도달 | 1.812초 |
| 관절형 / 6 N | 곡관에서 정체, 수직 진입 미확인 | 미도달 |

## 7. 2026-11-09 내용 검증

첨부된 [검증 프로그램](assets/gazebo-co2-2026-10-29/verify_records.py)으로 **180개 검사를 통과**했다. 질량 시험 10회 및 차체 비교 4회의 기록을 대상으로 다음을 확인했다.

- 질량별 SDF의 총 질량, 바퀴 수, 중력, 추진력, 연속 분사, 40 cm 시작 조건.
- CSV에서 판정식으로 도달 시간을 재계산하고 결과 JSON의 성공/실패·시간과 대조.
- 300~420 g의 20 g 간격 누락 여부, 400 g 성공·420 g 최초 미도달 분류.
- 질량 시험의 분사 시작 이후 기록이 연속으로 켜져 있는지, 분사 로그 존재 여부.
- 실패 조건의 기록이 30초/60초 제한까지 충분히 남아 있는지.

검증 중 **초기 별도 경로 시험의 `hvh/trajectory.csv`가 기존 `hvh/results.json`과 일부 일치하지 않는 문제**를 확인했다. 이 CSV는 GUI 재생과 동일 경로를 사용해 덮어써질 수 있다. 해당 묶음은 과거 자료로 보존하되 결론의 검증 근거에서 제외했다. 최종 경로 300 g 결과는 별도로 보존된 `mass_sweep/300g_sweep_seed42_30s.csv`에서 다시 확인했다. GUI에서 같은 telemetry 경로를 재사용하면 기록이 바뀔 수 있으므로 원본 증거 사본에서 직접 재생하지 않는 것을 권한다.

[검증 결과 JSON](assets/gazebo-co2-2026-10-29/verification.json)과 [파일 SHA-256 목록](assets/gazebo-co2-2026-10-29/SHA256.json)을 첨부했다. 해시는 Windows/Linux 체크아웃의 차이를 피하기 위해 줄바꿈을 LF로 정규화한 바이트 기준이다. 이 검증은 기록 일관성 검사이며, 물리 엔진 정확성·실제 마찰·실제 가스 성능 검증을 의미하지 않는다.

재검증은 Python 표준 라이브러리만 필요하다. 저장소 루트에서 다음을 실행한다.


## 8. 해석의 한계와 후속 실험

- CO₂ 카트리지·밸브·노즐 형상, 압력, 유량, 잔량 감소, 질량 감소, 온도 변화, 배압 및 가스 유동은 미구현이다. 3 N은 실제 제품에서 확인된 힘이 아니다.
- 총 질량에 장비가 포함된 것으로 가정했지만 실제 탑재 설계·치수·무게 분배는 미검증이다. 질량 추가는 몸체의 균일 분포로만 근사했다.
- 일정 모터 토크를 사용하며 전압, 배터리, 속도별 토크곡선, 제어·기어 효율 제한이 없다. 실제보다 유리한 주행이 나올 수 있다.
- 배관·바퀴의 마찰은 입력되어 있으나 실측 보정과 민감도 시험이 없다. 스프링 접촉력·바퀴 슬립·접촉 수의 계측도 아직 부족하다.
- 16각 단면과 분할 곡관은 실제 원형 PVC/엘보와 접촉 특성이 다르다. 치수 실측 및 형상 수렴성 시험이 필요하다.
- 상단 수평관에서의 분사 차단·감속·정지·회수 제어는 없다. 60초 미도달은 유한 시간 관측이며 영구적 불가능을 증명하지 않는다.

후속 검증은 실제 파이프 내경과 곡관 반경 측정, 바퀴-PVC 접지력/주행저항 측정, 모터 사양 반영, 가스 장치의 시간별 추진력 측정 순으로 진행한다. 이후 400~420 g 구간 세분화와 마찰·스프링·노즐 방향 민감도 시험을 수행해야 설계 한계로 해석할 수 있다.
