## 균열 및 변형 검사

| 검사 대상 | 조사한 접근 |
| --- | --- |
| 표면 균열 | 로봇에서 보이는 관 내벽을 LED로 비추고 카메라로 후보를 찾는다. |
| 벽 내부 균열 | 재료 내부를 검사할 수 있는 초음파 등의 센서를 검토한다. |
| 부식·벽 두께 감소 | 이번 조사에서 균열 검출 범위 밖으로 분류했다. |
| 찌그러짐·단면 변형 | 레이저나 라이다로 형상을 측정한다. |

- 금속관은 [초음파 검사 연구](https://link.springer.com/article/10.1186/s10033-018-0280-z), 콘크리트는 [타격식 검사 연구](https://arxiv.org/abs/2110.13125)를 조사했다.
- Evident PipeWIZARD는 위상 배열 초음파(PAUT), 일반 초음파, TOFD 등을 쓰는 상용 사례다. TOFD는 균열 끝에서 회절된 신호의 도착 시간으로 결함 크기를 추정한다. 원문에서는 내부 주행 로봇에 바로 적용하기 어렵다고 봤다.
- [ROSEN RoCD EMAT-C](https://www.rosen-group.com/en/global/rocd-emat-c-ultra)는 액체 접촉매질 없이 금속 가스관을 검사하는 EMAT 사례다. GUL Wavemaker는 유도 초음파로 긴 관 구간을 검사하는 사례다.

## 초음파 실험 장비 후보

| 후보 | 용도 | 당시 예상가 |
| --- | --- | --- |
| pic0rick 키트 | 송신, 수신 증폭, ADC, USB 전송 | $299 (약 42만 원) |
| 5 MHz 수직 탐촉자 | 기준 반사파 및 벽 두께 확인 | 5만~10만 원 |
| 4~5 MHz 45° 또는 60° 사각 탐촉자 | 균열 검출 | 8만~15만 원 |
| SMA/BNC 변환 케이블 | 보드와 탐촉자 연결 | 2만~5만 원 |
| 초음파 젤 | 탐촉자와 금속 사이의 공기 제거 | 약 1만 원 |

원문에 기록된 pic0rick 사양은 Raspberry Pi Pico 계열, 약 ±25 V 송신, 60 MS/s·10비트 ADC, 약 7.5~55.5 dB 수신 증폭, 단일 소자 1~10 MHz 탐촉자 지원이다. USB와 Python을 사용하며 회로도·PCB·펌웨어가 공개된 후보로 조사했다. $299는 [9월 27일 조사](2026-09-27-autonomous-inspection-design.md#초음파-개발과-조달)에서 과거 표기로 분류했다.

## 배관 지도 및 센서 후보

- **연결 지도**는 분기와 구간의 연결 관계를 나타낸다.
- **경로·중심선 지도**는 공간상의 진행 방향, 굽힘, 경사, 구간 길이를 나타낸다. 이 시점에는 대략적인 3D 중심선이 우선 후보였다.
- **내벽 형상 지도**는 벽 표면과 단면 형상을 복원한다. 균열은 탐지 시점의 위치와 연결해 지도에 표시하는 방안을 검토했다.

| 센서 | 얻는 정보와 제약 |
| --- | --- |
| 일반 카메라 | 균열 후보와 오염을 관찰한다. 조명, 반사, 무늬 부족의 영향을 받는다. |
| 스테레오 카메라 | 시차로 거리와 영상을 얻는다. 가까운 벽이나 무늬가 적은 벽에서 정합이 어렵다. |
| 구조광·레이저 링 | 벽에 투사된 선으로 단면과 변형을 측정한다. 반사·가려짐과 별도 위치 추정을 고려해야 한다. |
| 3D 라이다 | 터널이나 큰 관의 형상을 측정한다. 좁은 관에서는 최소 측정거리, 크기, 반복 형상이 제약이다. |
| 소나 | 탁한 물속의 형상을 측정한다. 해상도와 반사 특성이 광학 영상과 다르다. |

참고 사례는 [레이저 링 기반 관내 매핑](https://arxiv.org/abs/1907.12172), [카메라·IMU 기반 ORB-SLAM3](https://github.com/UZ-SLAMLab/ORB_SLAM3), [라이다·IMU 기반 FAST-LIO](https://github.com/hku-mars/FAST_LIO)다.
